    PROVEN FIXES CODIFIED IN THIS STANDARD:
    
          
    
            1. Subbar .grp Collision Rule:
    
            Never use .grp on subbar button toolbars! It will cascade into the Settings modal cards and squish all titles, sliders, and toggles into a single cramped row. Always scope subbar button groups to .subbar-grp.
          
    
          
    
            2. Modal Height Autosizing Formula:
    
            Never use hardcoded height: min(650px, 88vh) on .modal-sheet (it creates a giant 350px empty black void on short tabs).
    
            Always use: .modal-sheet { height: auto; max-height: 85vh; display: flex; flex-direction: column; }
    
            And: .modal-body-scroll { max-height: calc(85vh - 145px); overflow-y: auto; }
          
    
          
    
            3. Footer Button Alignment:
    
            Never give the Save button flex: 1 if Cancel has a fixed width. Use .modal-footer { display: flex; justify-content: flex-end; gap: 12px; } to keep CANCEL and SAVE side-by-side on the right with balanced 42px height.
          
    
          
    
            4. Default 3-Component View:
    
            On initial load, ONLY show: Departure/Base Banner (#homeBanner), Command HUD (#heroHud), and Guided Walkthrough (#panel-walkthrough with data-keep="1"). Set data-hidden="1" on all secondary panels, and unhide them on-demand when clicked.
